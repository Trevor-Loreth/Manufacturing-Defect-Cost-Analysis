## Stored Procedures
- **Component Inserts:** Created insert procedures for blades, motors, and frames that add new component serial numbers by factory. Each procedure automatically looks up the correct unit cost from the Factory Costs table before inserting the record, helping keep component cost data consistent.
- **Factory Costs Insert Update:** Created insert and update procedures for factory-level component costs. The insert procedure adds new component/factory cost records while preventing duplicates, and the update procedure changes existing unit costs while returning the old and new values for confirmation.
- **Inventory Insert Update:** Created an inventory insert procedure that adds finished products by linking each product serial number to its blade, motor, and frame serial numbers. The procedure checks for duplicate products and verifies that each component exists before inserting, helping protect referential integrity.

- **Sales and Returns Inserts:** Created sales and returns insert procedures with validation checks to protect data quality. The sales procedure prevents duplicate sales, verifies the product exists in inventory, and automatically calculates cost from component and assembly costs. The returns procedure verifies the product was sold, prevents duplicate returns, validates defect details, and records refund impact.
- **Sales Running Summary View:** Created a running summary view that combines sales and returns into one transaction timeline. The view calculates running totals for sales, costs, refunds, net sales, and profit, making it easier to track business performance over time.
